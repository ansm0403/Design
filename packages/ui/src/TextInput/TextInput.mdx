# TextInput

폼에서 텍스트를 입력받는 기본 컴포넌트. `label`·`helperText`·`error`를 한 덩어리로
제공하고, 접근성(`aria-invalid`, `aria-describedby`)을 기본 탑재한다.

**Controlled 방식 권장**: `value`와 `onChange`를 React state로 연결하면 입력값을
완전히 제어할 수 있어 폼 검증·초기화가 쉽다. `defaultValue`만 넘기는 비제어 방식도
동작한다.

## 접근성 포인트

- `useId`로 생성한 고유 id가 `label[htmlFor]` ↔ `input[id]`를 연결한다.
- `error` 있을 때: `aria-invalid="true"` + `aria-describedby`(에러 메시지 id) 자동 부여.
- `helperText`도 `aria-describedby`로 연결된다(에러와 헬퍼가 동시에 있으면 에러가 우선).
- 포커스 링은 래퍼가 `focus-within:`으로 그린다 — addon 유무와 무관하게 동일한 포커스 시각.
